# Avaliação Prática: Cardápio Digital Interativo

**Unidade Curricular:** UC6, Prototipação Rápida de Aplicações com IA  
**Modalidade:** Individual  
**Duração:** 3 horas  
**Ferramentas permitidas:** ChatGPT, Gemini, Claude, Lovable, GitHub Copilot e outras ferramentas de IA para desenvolvimento.

## Situação-problema

Uma lanchonete deseja modernizar seu atendimento disponibilizando um cardápio digital interativo.

Atualmente, os clientes precisam consultar os produtos diretamente com os atendentes. A empresa deseja uma aplicação web que permita visualizar os produtos disponíveis, selecionar itens e montar um pedido.

Você foi contratado para desenvolver um protótipo funcional dessa solução utilizando ferramentas de inteligência artificial para acelerar o processo.

## Requisitos obrigatórios

**RF01. Catálogo de produtos**

A aplicação deverá apresentar pelo menos seis produtos fictícios, contendo nome, preço, descrição e categoria.

**RF02. Categorias**

Os produtos deverão estar organizados em pelo menos duas categorias, com possibilidade de filtragem.

**RF03. Carrinho de compras**

O usuário deverá conseguir adicionar produtos ao carrinho.

**RF04. Controle de quantidades**

O usuário deverá conseguir aumentar ou diminuir a quantidade dos produtos selecionados e remover itens do carrinho.

**RF05. Cálculo automático**

A aplicação deverá calcular corretamente os subtotais e o valor total do pedido, considerando preços e quantidades.

**RF06. Finalização simulada**

O usuário deverá conseguir confirmar o pedido e visualizar uma mensagem de confirmação contendo o resumo dos itens selecionados. Não será necessário implementar pagamentos reais.

**RF07. Interface responsiva**

A aplicação deverá funcionar adequadamente em computadores e dispositivos móveis.

**RF08. Validação**

O sistema deverá impedir a confirmação de pedidos vazios e apresentar mensagens compreensíveis ao usuário.

## Utilização de inteligência artificial

O aluno deverá utilizar ferramentas de IA em pelo menos três momentos do processo: planejamento, geração ou implementação e validação ou correção.

O código gerado deverá ser analisado e testado antes da entrega.

## Entregas

1. Aplicação funcional executando localmente ou disponibilizada por um link acessível.
2. Repositório GitHub com o código-fonte do projeto.
3. Arquivo README.md contendo uma descrição da solução, instruções de execução e ferramentas utilizadas.
4. Registro de pelo menos três prompts utilizados, com breve explicação de sua finalidade.
5. Registro dos testes realizados e dos respectivos resultados.

## Restrições

A aplicação deverá utilizar produtos e informações fictícias. Não é necessário implementar autenticação, pagamento real, entrega, gerenciamento de estoque ou painel administrativo.

A avaliação considera o funcionamento do MVP e a capacidade de utilizar IA de forma crítica, não apenas a aparência da interface.
